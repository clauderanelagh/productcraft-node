# @productcraft/gen-fixture

The generator's test fixture: a package generated by `scripts/gen-sdk.mjs` from [`fixture.openapi.json`](./fixture.openapi.json). It is private and never published. Its generated output is golden-tested (`tests/generator.test.ts`), its per-operation test runs in CI, and its README region, `api.md` and `examples/gen-fixture/` show exactly what a product package gets.

```ts
import { Fixture } from "@productcraft/gen-fixture";

const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY, workspaceId: "9b2f6c1e-0d6a-4a63-9a43-2f1c3e4d5a6b" });
const widget = await fixture.widgets.create({ name: "Gadget" });
await fixture.widgets.updateStatus(widget.id, { status: "active" });
```

## Pagination

List methods return a `PagePromise`: `for await` walks every item across pages, `await` gives one page.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
for await (const item of fixture.webhooks.endpoints.list({ limit: 50 })) console.log(item);
const page = await fixture.webhooks.endpoints.list();
if (page.hasNextPage()) await page.getNextPage();
const all = await fixture.webhooks.endpoints.list().toArray({ maxItems: 500 });
```

## Errors

Every failure is a class you can catch. `APIError` carries `status`, `code`, `message`, `errors[]`, `requestId` and `docUrl`.

```ts
import { Fixture, NotFoundError, RateLimitError, APIError } from "@productcraft/gen-fixture";
const fixture = new Fixture();
try {
  await fixture.widgets.retrieve("00000000-0000-0000-0000-000000000000");
} catch (err) {
  if (err instanceof NotFoundError) console.log(err.code, err.requestId, err.docUrl);
  else if (err instanceof RateLimitError) console.log(err.retryAfter);
  else if (err instanceof APIError) console.log(err.status, err.errors);
  else throw err;
}
```

## Retries and timeouts

Network errors, 408, 429, 5xx and `409 IDEMPOTENCY_IN_PROGRESS` are retried twice by default with exponential backoff and jitter, honouring `Retry-After` up to 60 s. A POST or PATCH without an idempotency key is never retried. Each attempt times out after 60 s, so the worst case with defaults is about 3 minutes; pass `signal: AbortSignal.timeout(ms)` for an overall deadline.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ maxRetries: 3, timeout: 20_000 });
await fixture.webhooks.endpoints.list({}, { maxRetries: 0, signal: AbortSignal.timeout(5_000) });
```

## Idempotency

Writes that support it send an `Idempotency-Key` automatically and reuse it on every retry. Pass your own to make a retry across processes safe. If the API's idempotency store is unavailable it runs the request without it (fail-open), so a retry during that window can execute twice.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
const widget = await fixture.widgets.create({ name: "Gadget" }, { idempotencyKey: "order-1234" });
```

## Polling

`widgets.poll(id)` retrieves until `status` is terminal (`active`, `archived`), honouring `Retry-After`; `timeoutMs` (default 5 min) throws `APITimeoutError`.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
const done = await fixture.widgets.poll("9b2f6c1e-0d6a-4a63-9a43-2f1c3e4d5a6b", { intervalMs: 2_000, timeoutMs: 600_000 });
console.log(done.status);
```

`widgets.createAndPoll<T>(params)` creates, then polls; `metadata` is typed as `T` (a type assertion: the SDK does not validate it at runtime).

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
type Extracted = { title: string };
const done = await fixture.widgets.createAndPoll<Extracted>({ name: "Gadget" }, { timeoutMs: 600_000 });
console.log(done.metadata?.title);
```

## Webhooks

`fixture.webhooks.unwrap()` verifies the signature against the **raw** body and returns a typed `Fixture.UnwrapWebhookEvent`. The secret comes from `{ secret }`, the client's `webhookSecret`, or `PRODUCTCRAFT_FIXTURE_WEBHOOK_SECRET`.

Next.js route handler:

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture();
export async function POST(req: Request) {
  const event = await fixture.webhooks.unwrap({ payload: await req.text(), headers: req.headers });
  switch (event.type) {
    case "widget.archived":
      console.log(event.data);
      break;
    default:
      break; // UnknownWebhookEvent: types added later
  }
  return new Response(null, { status: 204 });
}
```

Express (keep the body raw):

```ts
import express from "express";
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture();
const app = express();
app.post("/webhooks", express.raw({ type: "application/json" }), async (req, res) => {
  const event = await fixture.webhooks.unwrap({ payload: req.body, headers: req.headers });
  console.log(event.type);
  res.sendStatus(204);
});
```

Hono:

```ts
import { Hono } from "hono";
import { Fixture } from "@productcraft/gen-fixture";
```

## Raw responses

Every returned object has a non-enumerable `lastResponse` (`requestId`, `status`, `headers`). `.withResponse()` adds the `Response` and parsed rate-limit headers.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
const id = "9b2f6c1e-0d6a-4a63-9a43-2f1c3e4d5a6b";
const obj = await fixture.widgets.retrieve(id);
console.log(obj.lastResponse.requestId);
const { data, response, requestId, rateLimit } = await fixture.widgets.retrieve(id).withResponse();
console.log(data, response.status, requestId, rateLimit?.remaining);
```

## Testing

`@productcraft/gen-fixture/testing` exports `createMockFetch()`, a `fetch` that answers every operation with its spec example. Override one operation by name.

```ts
import { Fixture } from "@productcraft/gen-fixture";
import { createMockFetch } from "@productcraft/gen-fixture/testing";
const fetch = createMockFetch();
const fixture = new Fixture({ apiKey: "test", workspaceId: "9b2f6c1e-0d6a-4a63-9a43-2f1c3e4d5a6b", fetch });
await fixture.webhooks.endpoints.list();
console.log(fetch.calls.length);
```

## Escape hatch

`.client` is the typed `openapi-fetch` client over the same credential and base URL (no retries). Use it for anything the resource methods do not cover.

```ts
import { Fixture } from "@productcraft/gen-fixture";
const fixture = new Fixture({ apiKey: process.env.PRODUCTCRAFT_API_KEY });
const { data, error } = await fixture.client.GET("/v1/regions");
console.log(data, error);
```
